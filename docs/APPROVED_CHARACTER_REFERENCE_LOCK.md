# PUPAL Approved Character Reference Lock (2026-11-06)

User-supplied approved visual reference files are archived separately in PUPAL_Approved_Character_References.zip. They are not GLB models.

## Canonical identities
- Momo: warm brown otter, rounded cheeks, large glossy eyes, soft detailed fur, yellow scarf, blue backpack at child stage.
- Lulu: orange-and-cream fox, oversized ears, full white-tipped tail, red scarf, adventure goggles.
- Pico: mint-green baby dragon, yellow horns, green wings, cream belly, explorer bag.

## Stage requirements
- Birth: character inside distinct egg with characteristic pattern.
- Baby: quadrupedal crawling or early walking, oversized head, expressive eyes, stage-specific proportions.
- Child: upright adventurer, backpack and accessories, developed posture and locomotion.
- No uniform scale-only growth.

## Emotion requirements
- Happy/Complete: smile, jump, celebration.
- Encourage: affirming gestures.
- Concern: gentle, no guilt-inducing or punitive behavior.
- Comfort: empathy and calm.
- Bored/Rest: independent reading or relaxing.
- Restart: hopeful animation.

## Visual acceptance
Target the provided polished CGI concept art. No emoji, SVG, flat images disguised as 3D, or primitive-only geometry. Require rigged GLB and real mobile preview before claiming completion.

## Important
Images attached in conversation are not automatically checked into GitHub. The canonical image package is supplied as a separate downloadable archive. Production-quality 3D character meshes are not yet produced.
